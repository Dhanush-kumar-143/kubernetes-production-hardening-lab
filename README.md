# Kubernetes Production Hardening and Troubleshooting Lab

A hands-on Kubernetes project for diagnosing broken clusters, troubleshooting production incidents, and applying production-grade hardening.

## Technology Stack
- Kubernetes with Minikube
- Docker
- kubectl
- Helm
- Git and Bash

## Project Goals
- Reproduce and troubleshoot common Kubernetes failures.
- Implement resource requests and limits.
- Configure liveness and readiness probes.
- Configure PodDisruptionBudgets and Horizontal Pod Autoscaling.
- Apply RBAC, NetworkPolicies, and pod security settings.
- Automate deployment, validation, and recovery.

## Troubleshooting Scenarios
Scenarios will be added incrementally, with reproduction steps, diagnosis, fixes, and validation.
